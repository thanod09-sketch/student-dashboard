# StudentHub Dashboard

A responsive student dashboard built with React, Vite, and Lucide icons. It brings student profile and ID details, attendance, courses, results, assignments, and campus announcements together in one view.

## Getting started

Install dependencies and start the local development server:

```sh
npm install
npm run dev
```

## Available commands

- `npm run dev` — start the Vite development server
- `npm run build` — create a production build in `dist`
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint
